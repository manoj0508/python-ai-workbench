# Python AI Workbench

A collection of small projects exploring how to build practical applications with Python and large language models (LLMs). Each project is organized in its own directory and includes its own dependencies and run instructions.

## Projects

### [AI Email Assistant](./ai-email-assistant/)

A Streamlit application that uses the OpenAI API to draft emails. Choose the email purpose, tone, recipient, and length, review generated emails in the current session, and download the latest result.

See the [AI Email Assistant README](./ai-email-assistant/README.md) for setup instructions, API key configuration, and details about its features.

## Getting started

1. Browse to a project's directory.
2. Follow that project's README to install dependencies and configure any required API credentials.
3. Run the project using its documented command.

Projects may require API keys. Keep credentials private and never commit them to the repository.
